# Detection Engineering Lab

A practical cybersecurity lab documenting detection engineering, threat hunting, SOC investigations, and incident response.

## Focus Areas

- Detection Engineering
- Threat Hunting
- SOC Investigation
- Incident Response
- Security Monitoring
- MITRE ATT&CK Mapping
- Detection Tuning

## Technologies

- Microsoft Sentinel / KQL
- Splunk / SPL
- Sigma
- Wazuh
- Windows & Sysmon
- MITRE ATT&CK

## What This Repository Covers

This repository documents practical approaches to:

- Developing and analyzing security detections
- Writing and understanding SIEM queries
- Investigating security alerts
- Performing threat-hunting exercises
- Mapping detections to MITRE ATT&CK
- Identifying false positives and tuning detections
- Developing SOC investigation and response workflows

## Disclaimer

All investigations, queries, datasets, and examples in this repository are created for educational and portfolio purposes. No confidential company, client, or production data is included.
